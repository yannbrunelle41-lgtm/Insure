# Insure

Intégration responsive de la page d’accueil d’Insure à partir d’une maquette Figma. J’ai réalisé ce projet pendant ma formation en développement web et web mobile.

## Mise en page

- Sur mobile la photo passe au-dessus du texte et la navigation se replie dans un menu burger
- À partir de 1024 pixels la navigation s’affiche dans l’en-tête et la photo se place à droite du texte
- La section **We’re different** présente trois avantages et le pied de page regroupe les liens et les réseaux sociaux

## Technologies utilisées

- HTML pour structurer la page
- CSS et Flexbox pour adapter la mise en page aux différentes tailles d’écran
- JavaScript pour ouvrir et fermer le menu mobile et mettre à jour son état avec `aria-expanded`
- Polices Karla et DM Serif Display hébergées dans le projet

## Voir le projet en local

Ouvre `index.html` dans ton navigateur.

## Ce que j’ai appris

C’était ma première intégration de maquette. J’ai appris à repérer les blocs dans Figma et à adapter leur disposition entre mobile et desktop. C’est aussi sur ce projet que j’ai écrit mes premières lignes de JavaScript pour faire fonctionner le menu burger.
